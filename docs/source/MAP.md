## Translations

`source/locale/` holds the gettext catalogues (`.po`): zh_TW, zh_CN, ru, ko, ja.

`docs/readme_translations/` holds the translated README (`README.<lang>.md`, same languages),
written by `docs/source/batch_translate_po.py` before it translates the catalogues; the script
also refreshes the language bar in `README.md`, `test/README.md` and every translation, and
keeps `readme_cache.json` as the memory that makes a rerun request only changed blocks.

## Known gaps

- `docs/source/changes/`, `docs/source/design/` and the `CHANGELOG` do not exist yet (their templates are ready).
- API pages under `docs/source/api/` are generated by `sphinx-apidoc` (`-T`, so it writes no `modules.rst`); rerun it after adding or removing a *module*. The entry point is the hand-written `docs/source/api/index.rst` ("API Reference"), linked from the main toctree; page options live in `autodoc_default_options` in `docs/source/conf.py`.
- Docstring backlog: 106 open ruff `D` findings (59 of them undocumented public API); public-API coverage measured by interrogate is 66.1%, gated by `fail-under = 65.0` in `pyproject.toml`.
- No Doxygen configuration (no `Doxyfile`); `PyFlow/crypto_api/include/` uses plain block comments.
- Docs warnings: `docs/source/_static` missing (`html_static_path` names it in `docs/source/conf.py`, but the directory does not exist).
- `docs/reBuild.sh` shells out to `python3.14` for the translation step, so a full translation rebuild needs that interpreter even though the package supports Python 3.10+.
