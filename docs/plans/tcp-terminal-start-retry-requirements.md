# 需求卡 A：TCP 实例终态与启动、连接重试

状态：需求方已确认以下边界，授权记录和[计划拆分](tcp-control-session-lifecycle-plan.md)。**不是 E1/E2 的追加实现**。恢复的草稿仅涉及 A0；后续原子未授权实施。

## 目标与接口

终态关闭约束的是一个实例，不是宿主进程、地址或线程。旧 Server 不再监听、旧 Client 不再建立控制会话；端口可用时，新实例可以在同一 IP、同一端口工作。普通断线不是终态，未关闭的 Client 可以自动重连。

- 保持 `start_TCP_Server()`、`stop()`、`connect()`、`start_TCP_client()`、`close()` 的签名。显式关闭后的旧 Server 再启动直接返回，不 bind/listen；旧 Client 再连接返回 `False`，不新开 socket。保留已丢弃传输进度实例原有的拒绝契约，不让迟到的启动调用破坏 `delete_config()` 的状态判断。
- `stop()` 不必等另一个普通线程里的 `start_TCP_Server()` 返回；`close()` 不必等另一个普通线程里的 `connect()` 返回。返回时，旧候选 socket 已退休，旧启动线程不能再发布 `running=True`、登记控制 socket、启动新 reader 或接纳新客户端。已发给操作系统的 TCP 请求不是可撤回的消息：对端可以观察到该请求，但旧 Client 不因此发布会话，输掉竞争的 `connect()` 返回 `False`。
- 关闭要通知库内等待者（包括重试和模式协商），不承诺调用者线程的固定返回时限。**不改变** E1 的池外关闭无界等待已接纳 worker、池内自停不 self-join、重复关闭仍 flush 的行为。
- 首次连接立即尝试。`is_wait_server=True` 时，单次尝试超时或被拒后，如仍要重试，等 **1 秒**，终态关闭可打断；`False` 不新增内层重试。固定本地控制端口不可用时保留**一次立即回退**到 OS 选择的本地端口（包括既有 Windows 冲突分支），回退前也必须允许终态胜出。外层 auto-reconnect 已有的 1 秒间隔保留，不为同一次失败叠加内外两次延时。

## 必验路径与证据

| 路径 | 必须看见的结果 |
|---|---|
| A-S：Server 启动前已停、bind/listen 成功但尚未发布时停、已发布后停；线程/asyncio 接收模式 | 真实 listener 不再接入；控制住启动线程的收尾时，新实例仍可绑定同一地址；放行旧线程后没有状态复活或遗留客户端。待启动调用退栈后，`delete_config()` 不会因假 `running` 被拒绝。 |
| A-C：首次 connect、显式晚到的 connect、TCP 已连但尚未发布、reader/协商建立期间关闭 | 用真实 peer 区分“一次在途 TCP 到达”与“新会话成功”；关闭胜出后没有晚启动的 reader、无效控制登记或新的连接尝试；不把库内等待延至原超时。关闭不 join 调用方业务线程。 |
| A-R：不可达/超时/被拒，首连和断线重连，等待开/关、1 秒等待中关闭、正常重新连通 | 记录每次实际尝试和等待的起止：首尝试无延时，被拒/超时后重试有间隔，无忙轮询；关闭能唤醒，不再向恢复上线的监听端发新请求；正常重连后仍用原 executor。 |
| A-F：固定非零本地端口冲突，立即回退、回退前关闭；本地端口为 `0`/`None`、其他错误 | 未关闭时只回退一次且可真实连通；关闭胜出不再进行回退，非冲突不走此分支。远端地址/端口不因本地回退改变。 |

## 范围、数据与风险

产品范围限 `PyFlow/network_api/connect_tcp.py` 的实例启动、控制会话发布和关闭交接。风险**高**：仅给 `running` 加锁而不交接候选 socket/reader 仍会漏清理；锁不能跨网络 I/O、等待用户 handler、join 或 executor drain。握手、加密、传输 FID/进度、备用端口的既有错误判定不改，不记录正文或密钥。不新增设置、超时参数或退出进程逻辑。

排除同一活实例同时两次启动，及[需求卡 B](tcp-session-port-ownership-requirements.md)的端口范围、文件等待与扩展资源。不得用重建 executor、延迟断言、改变 CI/依赖/coverage 或跳过平台分支达标。已确认的是需求，不是任意竞争时序已经通过；逐原子证据见[计划](tcp-control-session-lifecycle-plan.md)。
